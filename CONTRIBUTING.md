# Contributing to formatte

Thanks for your interest in the formatte ecosystem.

## What is formatte?

formatte is a **splinter organization**. We are building a D language remake of the ideas behind [dprint](https://github.com/dprint)—a unified, pluggable code formatter. We are not affiliated with the original dprint project.

## How to contribute

- Open issues and discussions in the repo that fits your topic.
- Follow the code and style guidelines in each repository.
- Keep the D spirit: readable, fast, and maintainable.

## Attribution

We acknowledge the original [dprint](https://github.com/dprint) project and its authors. Our work is a fresh implementation in D, not a fork of the original codebase.
