# formatte

**Format, unified.** A D language remake of the dprint ecosystem.

---

We are a **splinter org**. This organization is not affiliated with [dprint](https://github.com/dprint) or dprint.dev. The original pluggable formatter platform and its ecosystem inspired this effort; we are rewriting the core and tooling in **D** with a clean slate.

**Website:** [formatte.dev](https://formatte.dev)

The “d” in formatte.dev is deliberate: **formatte.d** - D for the language, .dev for the home.

---

Repositories here will hold the D implementation and editor integrations. Original project: [dprint/dprint](https://github.com/dprint/dprint).
